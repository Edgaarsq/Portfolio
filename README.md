## Design Philosophy

The portfolio follows a **premium product-experience approach**.

The design language is inspired by Apple's philosophy rather than simply copying its visual identity.

### Principles

**Minimalism**

Only what matters.

**Typography**

Clear hierarchy and strong typography create structure without unnecessary decoration.

**Motion**

Animations are subtle, purposeful, and responsive to the user's interaction.

**Depth**

Layers, blur, shadows, transparency, and spatial relationships create a sense of depth.

**Precision**

Every spacing value, interaction, transition, and component has a purpose.

**Performance**

A beautiful interface should still feel fast.
